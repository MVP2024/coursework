# MoneyMetrics

MoneyMetrics - это проект для анализа финансовых данных, включая загрузку курсов валют, фильтрацию транзакций и анализ расходов и доходов.

## Установка

Для установки необходимых зависимостей выполните следующие шаги:

1. Убедитесь, что у вас установлен Python 3.7 или выше. Вы можете скачать его с [официального сайта Python](https://www.python.org/downloads/).
2. Клонируйте репозиторий:

    ```
    git clone https://github.com/yourusername/MoneyMetrics.git
    ```

    Замените `yourusername` на ваше имя пользователя на GitHub. Эта команда создаст локальную копию репозитория на вашем компьютере.

3. Перейдите в директорию проекта:

    ```
    cd MoneyMetrics
    ```

    Команда `cd` (change directory) используется для перехода в указанную директорию. После выполнения этой команды вы окажетесь в папке `MoneyMetrics`, где находятся все файлы проекта.

4. Установите зависимости:

    ```
    pip install -r requirements.txt
    ```

    Эта команда установит все необходимые библиотеки и зависимости, указанные в файле `requirements.txt`, которые нужны для работы проекта.

5. Создайте файл `.env` в корневой директории проекта и добавьте ваши API ключи:

    ```plaintext
    API_KEY_currency=ваш_ключ_валютного_API
    API_KEY_stock_price=ваш_ключ_API_для_акций
    ```

    Замените `ваш_ключ_валютного_API` и `ваш_ключ_API_для_акций` на ваши реальные API ключи. Файл `.env` используется для хранения конфиденциальной информации, такой как API ключи, которые не должны быть опубликованы в репозитории.


## Использование

### Загрузка данных из Excel

Функция `load_data_from_excel(file_path: str) -> List[Dict[str, Any]]` загружает данные из Excel и преобразует их в список словарей. Используйте эту функцию для загрузки ваших финансовых данных.

### Анализ транзакций

Функция `analyze_transactions(transactions: List[Dict[str, Any]])` анализирует транзакции и возвращает результаты анализа. Это может включать в себя подсчет расходов и доходов по категориям.

### Получение курсов валют и цен акций

Используйте функции `get_currency_rates(api_key: str, base_currency: str, target_currencies: List[str])` и `get_stock_price(stock_symbols: List[str], api_key: str)` для получения актуальных курсов валют и цен акций. Не забудьте указать ваши API ключи в файле `.env`.

### Сохранение результатов

Функция `main` сохраняет полученные данные о курсах валют и ценах акций в файл `user_settings.json` в корневой директории проекта. Это позволяет вам сохранять результаты анализа и использовать их в дальнейшем.

## Тестирование

Проект включает тесты, написанные с использованием `pytest`. Для запуска тестов выполните следующую команду:

```bash
pytest --cov=src --cov-report=term-missing
    ```
Это позволит вам проверить покрытие кода и убедиться, 
что все функции работают корректно. Тесты охватывают различные сценарии, включая успешные операции и обработку ошибок.


**Установка в PyCharm**

Чтобы установить проект в PyCharm, выполните следующие шаги:
1. Откройте PyCharm и выберите "Open" или "Import Project".

2. Выберите директорию, в которую вы клонировали проект MoneyMetrics.

3. После открытия проекта, PyCharm может предложить установить зависимости. Если этого не произошло, откройте терминал внутри PyCharm и выполните:
    ```
    poetry install
    ```
4. Убедитесь, что вы используете интерпретатор Python, установленный через Poetry. 
Вы можете настроить интерпретатор в настройках проекта (File -> Settings -> Project: <имя проекта> -> Python Interpreter).
