# MoneyMetrics

MoneyMetrics - это проект для анализа финансовых данных, включая загрузку курсов валют, фильтрацию транзакций и анализ расходов и доходов.

## Установка

Для установки необходимых зависимостей выполните следующие шаги:

1. Убедитесь, что у вас установлен Python 3.7 или выше. Вы можете скачать его с [официального сайта Python](https://www.python.org/downloads/).
2. Клонируйте репозиторий:

   ```
   git clone https://github.com/yourusername/MoneyMetrics.git
   ```
Замените yourusername на ваше имя пользователя на GitHub.



3. Перейдите в директорию проекта:
    ```
    cd MoneyMetrics
    ```
4. Установите зависимости:
    ```
   pip install -r requirements.txt
   ```
5. Создайте файл .env в корневой директории проекта и добавьте ваши API ключи:
```
API_KEY_currency=ваш_ключ_валютного_API
API_KEY_stock_price=ваш_ключ_API_для_акций
```
Замените ваш_ключ_валютного_API и ваш_ключ_API_для_акций на ваши реальные API ключи.
