# MoneyMetrics

MoneyMetrics - это проект для анализа финансовых данных, включая загрузку курсов валют, фильтрацию транзакций и анализ расходов и доходов.

## Установка

Для установки необходимых зависимостей выполните следующие шаги:

1. Убедитесь, что у вас установлен Python 3.7 или выше. Вы можете скачать его с [официального сайта Python](https://www.python.org/downloads/).
2. Клонируйте репозиторий:

    ```
    git clone https://github.com/yourusername/MoneyMetrics.git
    ```

    Замените `yourusername` на ваше имя пользователя на GitHub. Эта команда создаст локальную копию репозитория на вашем компьютере.

3. Перейдите в директорию проекта:

    ```
    cd MoneyMetrics
    ```

    Команда `cd` (change directory) используется для перехода в указанную директорию. После выполнения этой команды вы окажетесь в папке `MoneyMetrics`, где находятся все файлы проекта.

4. Установите зависимости:

    ```
    pip install -r requirements.txt
    ```

    Эта команда установит все необходимые библиотеки и зависимости, указанные в файле `requirements.txt`, которые нужны для работы проекта.

5. Создайте файл `.env` в корневой директории проекта и добавьте ваши API ключи:

    ```plaintext
    API_KEY_currency=ваш_ключ_валютного_API
    API_KEY_stock_price=ваш_ключ_API_для_акций
    ```

    Замените `ваш_ключ_валютного_API` и `ваш_ключ_API_для_акций` на ваши реальные API ключи. Файл `.env` используется для хранения конфиденциальной информации, такой как API ключи, которые не должны быть опубликованы в репозитории.


## Использование

### Основная функция анализа `events()`

#### Комплексный анализ финансовых данных

Функция `events(date_str: str, range_type: str = "M")` является ключевым инструментом проекта:

- **Параметры**:
  - `date_str`: Дата в формате "YYYY-MM-DD"
  - `range_type`: Тип диапазона анализа
    - `'W'`: неделя
    - `'M'`: месяц (по умолчанию)
    - `'Y'`: год
    - `'ALL'`: все доступные данные

- **Возможности**:
  - Фильтрация транзакций по выбранному периоду
  - Анализ расходов и доходов
  - Получение актуальных курсов валют
  - Загрузка текущих цен акций

- **Пример использования**:
    ```
  # Анализ транзакций за текущий месяц
  result = events("2023-12-15", "M")
    ```
    ```
  # Анализ всех транзакций до указанной даты
  result_all = events("2023-12-31", "ALL")
    ```
### Функции проекта

#### Определение времени суток
Функция `get_greeting()` возвращает приветствие в зависимости от текущего времени:
- "Доброе утро" (5:00 - 11:59)
- "Добрый день" (12:00 - 17:59)
- "Добрый вечер" (18:00 - 22:59)
- "Доброй ночи" (23:00 - 4:59)

#### Поиск личных переводов
Функция `find_personal_transfers(transactions)` анализирует транзакции и выявляет переводы физическим лицам.

#### Инвестиционный банкинг
Функция `investment_bank(month, transactions, limit)` помогает отслеживать округления транзакций для накопления средств.

### Отчётность

#### Траты по категории
Функция `spending_by_category(transactions, category, date)` формирует отчет о тратах по выбранной категории за указанный период.

#### Получение курсов валют для указанных валют
Функция `get_currency_rates(base_currency="RUB", target_currencies=["EUR", "USD"])` предоставляет актуальные котировки валют


#### Получение текущих цен акций
Функция `get_stock_price(symbols)` предоставляет актуальные котировки акций

#### Полный анализ расходов и доходов
Функция `analyze_transactions(transactions)` выполняет глубокий анализ финансовых транзакций

## Тестирование

Проект включает тесты, написанные с использованием `pytest`. Для запуска тестов выполните следующую команду:
    ```
    pytest --cov
    ```

Это позволит вам проверить покрытие кода и убедиться, 
что все функции работают корректно. Тесты охватывают различные сценарии, включая успешные операции и обработку ошибок.

## Логирование и отладка
### Декоратор @report_to_file()
## Декоратор автоматически создает два типа файлов:
1. decorator_out.json:
    - Содержит результаты выполнения функций
    - Структурированный JSON-формат
    - Сохраняет входные и выходные данные функций

2. Файлы логирования (logs/):
    - Подробная информация о выполнении функций
    - Включает:
        - Время выполнения
        - Входные параметры
        - Промежуточные состояния
        - Возможные ошибки
        - Уровни логирования (INFO, WARNING, ERROR)

Чтобы установить проект в PyCharm, выполните следующие шаги:


Вы можете настроить интерпретатор в настройках проекта (File -> Settings -> Project: <имя проекта> -> Python Interpreter).
